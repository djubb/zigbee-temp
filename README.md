# Zigbee Датчик Температуры (3× DS18B20)

Zigbee-устройство на базе ESP32-C6 для измерения температуры тремя датчиками
DS18B20 на одной 1-Wire шине. Питается от USB-C (постоянно), в сети выступает
как **Router** — укрепляет mesh для других (в т.ч. battery-powered) устройств.

---

## Железо

| Компонент | Модель | Примечания |
| --------- | ------ | ---------- |
| Контроллер | ESP32-C6 SuperMini | Постоянное питание через USB-C |
| Сенсоры | 3× DS18B20 | Общая 1-Wire шина, свой уникальный ROM-адрес у каждого |
| Терминал | Plugable Terminal v1738 | Клеммы для 3 датчиков, pull-up резистор 4.7кОм для DATA уже на плате |

## Подключение

Терминальная плата подключается к ESP всего тремя штырьками — без проводов:

```text
v1738:     GND — VCC — DATA
SuperMini: GND — 3V3 — GPIO2
```

> **GPIO2 выбран намеренно** (main/config.h): это не strapping-пин (4/5/8/9/15),
> не нативные USB D-/D+ (12/13 — заняты постоянно, т.к. плата всегда на USB-питании),
> не пин антенного переключателя (3/14) и не онбордовый LED (8).
>
> **Перед пайкой штырьков впритык обязательно сверьте физический порядок пинов
> на вашем экземпляре SuperMini и на плате v1738** — GPIO в `config.h` легко
> поменять одной строкой, если расположение на вашей плате отличается.

Все 3 датчика DS18B20 подключаются к одним и тем же трём линиям (GND/VCC/DATA) —
это штатный режим 1-Wire, каждый сенсор идентифицируется своим уникальным
64-битным ROM-адресом.

## Прошивка

Прошить можно прямо в браузере (Chrome / Edge):

**[Открыть веб-прошивалку](https://djubb.github.io/zigbee-temp/)**

1. Подключите ESP32-C6 по USB
2. Нажмите кнопку «Install»
3. Выберите COM-порт устройства
4. Дождитесь окончания прошивки

Если устройство не определяется — зажмите кнопку **BOOT** перед подключением USB.

## Сборка из исходников

Требуется [ESP-IDF v5.3+](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/index.html).

```bash
git clone https://github.com/djubb/zigbee-temp.git
cd zigbee-temp
idf.py set-target esp32c6
idf.py build
idf.py flash
```

## Подключение к Home Assistant

1. Перейдите в **Настройки → Устройства и службы → ZHA**
2. Нажмите **Добавить устройство**
3. Включите питание датчика по USB-C — при первом старте он автоматически
   попробует присоединиться к сети (network steering)
4. После подключения появятся 3 отдельные сущности температуры — по одной на
   каждый DS18B20 (эндпоинты 10/11/12, привязка к физическому датчику
   стабильна между перезагрузками — по возрастанию ROM-адреса)

## Сброс к заводским настройкам

- Удалите устройство из ZHA-интерфейса — девайс перейдёт в режим ожидания сопряжения
- Либо сотрите flash: `idf.py erase-flash`, затем прошейте заново

> При смене конфигурации Zigbee-кластеров необходимо стирать flash во избежание
> boot loop из-за несовместимости NVS-хранилища.
